## 如何编译运行

每个 `.c` 文件都可以独立编译运行（内含自测）。

```bash
# 1. 创建输出目录（只需一次）
mkdir -p build

# 2. 编译
gcc -Wall -Wextra 02-stack-queue/seq-stack.c -o build/seq-stack

# 3. 运行
./build/seq-stack
```

Windows PowerShell：

```powershell
mkdir build
gcc -Wall -Wextra 02-stack-queue/seq-stack.c -o build/seq-stack.exe
.\build\seq-stack.exe
```

## 文件约定

每个 `.c` 文件按统一结构编写：

1. **文件头注释**：原理、复杂度、易错点
2. **实现**：核心函数
3. **测试**：`test_xxx()` 函数
4. **`main`**：调用测试并输出结果
